# astrbot_plugin_niko_danmaku

NiKo 弹幕播报插件。

插件会定时间隔从弹幕网站 `sb6657.cn` 搜索一条与 `niko / NiKo` 相关的弹幕，并自动推送到已绑定的群聊或私聊。

## 功能

- 支持定时间隔播报
- 支持绑定多个群聊 / 私聊
- 绑定会话之间独立定时、独立短期去重，避免一条弹幕被一次性群发到所有群
- 同一个群即使被不同管理员重复绑定，也会按群号自动归一，只保留一个推送目标
- 支持手动测试获取一条弹幕
- 支持解绑当前会话
- 支持主关键词和额外关键词
- 支持控制是否显示推送前缀
- 支持控制是否显示标签、点赞、复制、投稿时间等附加信息
- 支持启动后立即播报
- 已绑定会话可阻止 LLM 自动回复，避免出现非弹幕消息
- 所有 `/niko弹幕...` 管理命令仅限 AstrBot 管理员使用

## 安装

将插件目录放入 AstrBot 插件目录：

```bash
AstrBot/data/plugins/astrbot_plugin_niko_danmaku
```

目录结构应为：

```text
astrbot_plugin_niko_danmaku/
├── main.py
├── metadata.yaml
├── requirements.txt
├── _conf_schema.json
└── README.md
```

然后在 AstrBot WebUI 的插件管理页面中重载插件。

## 依赖

本插件使用 `httpx` 请求弹幕网站接口。

```txt
httpx>=0.27.0
```

如果 AstrBot 未自动安装依赖，可手动进入 AstrBot 环境安装：

```bash
pip install "httpx>=0.27.0"
```

## 权限说明

所有 `/niko弹幕...` 命令仅限 AstrBot 管理员使用。

请在 AstrBot WebUI 中把需要管理插件的用户加入管理员列表：

```text
Config -> General Config -> admins
```

非管理员发送插件命令时，插件会停止事件传播并提示权限不足，避免命令继续交给其它插件或 LLM 处理。

## 使用方法

### 绑定当前会话

```text
/niko弹幕绑定
```

绑定后，插件会按照配置的间隔自动向当前会话推送弹幕。

### 取消绑定

```text
/niko弹幕解绑
```

解绑后，会取消当前会话的定时任务，并清理当前会话的短期去重缓存。

### 立即测试

```text
/niko弹幕测试
```

会立即从弹幕网站获取并发送一条相关弹幕。

### 查看状态

```text
/niko弹幕状态
```

可查看当前会话是否已绑定、绑定会话数量、关键词、播报间隔、前缀开关、附加信息开关、LLM 拦截开关等。

### 临时修改播报间隔

```text
/niko弹幕设置间隔 30
```

表示每 30 分钟播报一次。

注意：这是运行时临时修改，插件重启后会恢复为配置文件中的 `interval_minutes`。修改间隔后，所有已绑定会话的定时任务会重启。

### 临时开启或关闭附加信息

开启：

```text
/niko弹幕附加信息 开
```

关闭：

```text
/niko弹幕附加信息 关
```

关闭后只会显示弹幕正文，不显示标签、点赞、复制、投稿等信息。

### 临时开启或关闭推送前缀

开启：

```text
/niko弹幕前缀 开
```

关闭：

```text
/niko弹幕前缀 关
```

关闭后不会显示 `push_prefix`，只发送弹幕正文和可选附加信息。

### 临时设置额外关键词

```text
/niko弹幕额外关键词 尼扣,虾,三楼,小孩
```

清空：

```text
/niko弹幕额外关键词 清空
```

注意：这是运行时临时修改，插件重启后会恢复为配置文件中的 `extra_keywords`。

## 配置项

插件支持通过 AstrBot 配置面板修改以下选项。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `base_url` | `https://hguofichp.cn:10086` | sb6657 后端接口地址 |
| `keyword` | `niko` | 主搜索关键词 |
| `extra_keywords` | `尼扣,虾` | 额外搜索关键词，多个关键词用逗号分隔 |
| `page_size` | `50` | 每次搜索返回数量 |
| `interval_minutes` | `60` | 定时播报间隔，单位分钟 |
| `push_prefix` | `【NiKo 弹幕播报】` | 推送消息前缀 |
| `show_prefix` | `true` | 是否显示推送消息前缀 |
| `include_meta` | `true` | 是否显示标签、点赞、复制、投稿等附加信息 |
| `push_on_start` | `false` | 插件启动后是否立即播报一次 |
| `block_llm_in_bound_targets` | `true` | 已绑定会话中是否阻止 LLM 自动回复 |
| `no_repeat_cache_size` | `200` | 每个会话的短期去重缓存数量 |

## 数据存储

插件会把已绑定的会话保存到：

```text
data/plugin_data/astrbot_plugin_niko_danmaku/targets.json
```

插件重启后会自动读取该文件，继续向已绑定会话推送。

## 工作原理

插件启动后会：

1. 读取已绑定会话；
2. 按群号 / 私聊用户归一化绑定目标，自动清理同群重复绑定；
3. 为每个会话创建独立定时任务；
4. 每个会话按自己的定时任务调用 sb6657 后端搜索接口；
5. 使用主关键词和额外关键词进行搜索；
6. 过滤正文中包含相关关键词的弹幕；
7. 按会话独立短期去重；
8. 随机选择一条；
9. 只推送到对应会话。

插件优先请求：

```text
POST /machine/Query
```

请求体示例：

```json
{
  "D": "油猴",
  "barrage": "niko"
}
```

如果该接口失败，会回退请求：

```text
POST /machine/pageSearch
```

请求体示例：

```json
{
  "barrage": "niko",
  "tags": "",
  "sort": 0,
  "pageSize": 50,
  "pageNum": 1
}
```

## 常见问题

### 非管理员能不能绑定？

不能。所有 `/niko弹幕...` 命令都使用 AstrBot 管理员权限限制，并且额外做了事件传播拦截。

### 为什么绑定群里普通聊天不会触发 LLM 回复？

默认 `block_llm_in_bound_targets = true`。这是为了避免引用弹幕或上下文感知插件导致机器人继续生成“测试成功”“我来修”等非弹幕消息。

如果你确实希望绑定群仍然保留普通 LLM 聊天能力，可以在配置中关闭该选项。

### 没有自动推送怎么办？

请检查：

1. 是否由 AstrBot 管理员在目标群聊 / 私聊发送过 `/niko弹幕绑定`；
2. 插件是否已启用；
3. `httpx` 是否安装成功；
4. AstrBot 日志中是否有请求接口失败的报错；
5. `base_url` 是否仍然可用；
6. `interval_minutes` 是否设置得过大。

### 测试命令返回“没搜到 niko 相关弹幕”怎么办？

可能原因：

- 弹幕网站接口暂时不可用；
- 后端地址发生变化；
- 搜索接口返回结构变化；
- 当前关键词搜索结果为空；
- 过滤关键词过少。

可以尝试设置额外关键词：

```text
/niko弹幕额外关键词 尼扣,虾,三楼
```

或在配置中修改：

```text
extra_keywords = 尼扣,虾,三楼,小孩
```

### 会不会重复发送同一条弹幕？

插件内置短期去重缓存，默认每个会话缓存最近 `200` 条已发送记录。

如果可选弹幕数量较少，缓存耗尽后仍可能再次发送旧弹幕。

### 为什么同一个群以前会一次收到两条？

旧版本直接保存 AstrBot 的 `unified_msg_origin`。某些平台的群聊 origin 会包含发送者 ID，同一个群被不同管理员绑定时，可能保存出多个 origin，但它们最终都指向同一个群。

当前版本会按群号归一化绑定目标，启动时会自动清理旧数据中的同群重复绑定。
